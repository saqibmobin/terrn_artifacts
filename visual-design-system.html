The Amber Signal Rule (Invariable Core Law)

Amber is quarantined strictly for live telemetry and data readouts (coordinates, feature counts, slider values, AI processing status). Never use amber for generic UI buttons, hover washes, or decorative icons. Dark mode uses #F59E0B (14.8:1 contrast); Light mode darkens to #D97706 to maintain WCAG AA compliance (4.6:1).
